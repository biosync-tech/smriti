02Value proposition per layer

What each layer sells, to whom, and the single line that captures it.

Smriti — substrate

Agent memory you can audit

Bi-temporal graph + hash-chained writes + provenance scoring. Sold as OSS today; the moat is the design, not the code.
  • Buyer: dev/infra lead at an AI-native startup
  • Monetize: enterprise license + support (Red Hat model)
  • Wedge: integrity layer — nothing else in the memory category has it
DocFlow — engine

PDF → structured facts, auditable

Horizontal extract/validate/generate. Same API for invoice, contract, protocol. Writes through Smriti — one audit chain, not two.
  • Buyer: dev building an AP / clinical / legal workflow
  • Monetize: usage-based API + self-hosted license
  • Wedge: claim-span provenance baked into every extraction
Gemma 4B — runtime

Local LLM with no BAA required

Entire extraction tier runs on customer hardware. PHI never transits a third party. Zero marginal cost per call.
  • Buyer: any regulated vertical (clinical, legal, finance)
  • Monetize: implicit — unlocks premium pricing on verticals
  • Wedge: HIPAA/GDPR story without cloud-AI lock-in
Verticals — thin apps

One JTBD, priced per workflow

Branded separately. Opinionated about one workflow. UI is agent input + output. Reuses substrate + engine + runtime.
  • Buyer: clinical ops head / AP lead / research PI
  • Monetize: per-study / per-site / per-engagement
  • Wedge: depth over breadth — no chat, no dashboards

03The Gemma 4B strategic wedge

Why a 4B local model is not a cost optimization — it's a category definition.

One sentence: your stack is the only one that ships PHI-never-leaves-the-box as a default, not a premium tier.

compliance · no BAA required with any LLM vendor
cost · $0 marginal LLM spend per extraction
deployment · Mac mini to air-gapped rack, same binary
latency · ~200 tok/s local beats cloud round-trip
Every competitor in this category (Mem0, Zep, Letta, Mendable, Humata, Hebbia) assumes cloud-LLM dependency. Gemma 3 4B + Ollama + Smriti + DocFlow collapses the entire stack onto customer hardware. For clinical, legal, defense, and pharma buyers — that is the whole sale. It also rewrites your unit economics: per-extraction price stays flat while COGS falls to compute + electricity. That is how you price per-study at $5k and still run 80% gross margin.
Tiered LLM routing
Extraction tier → Gemma 4B local (always). Synthesis tier → optional: customer keeps it local on Gemma 27B / Llama 70B OR routes to Claude/GPT with their own BAA. You never hold the BAA.
Hardware menu
Dev trial: MacBook with 16GB. Pilot: Mac mini M2 16GB ($800). Production: 1U Linux server with a single consumer GPU ($2-4k). Rack-scale: 4× H100 for 4B fleet ($100k+ customer CAPEX, zero yours).
Differentiation story
"Your memory layer and your extraction engine, running on your own hardware, with the same audit guarantees as our cloud SaaS — and priced per workflow, not per token." That is the pitch no competitor can reproduce without rebuilding from scratch.

05Packaging moves that fall out of this

Concrete pricing shapes that become viable once the stack is local-first.

$100–250k/yr per sponsor. Ships as a Docker Compose bundle: Smriti + DocFlow + Gemma 4B + reviewer UI. Includes validation package, SLA, support. Regulated buyers will pay this without blinking.
02 · Per-protocol engagement

Transfer Sprint

$8–15k flat per protocol transfer. 4-week engagement. Installs the stack at customer site, loads documents, delivers readiness report. Converts to subscription after second success.

For non-regulated buyers

Standard SaaS on your cloud for academic / research / finance verticals that don't need HIPAA. $99–499/mo. Usage-priced overages. This is InvoiceBot and ResearchDesk.
